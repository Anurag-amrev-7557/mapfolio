# Security Policy 🛡️

## Supported Versions

We actively provide security updates for the following versions of Mapfolio:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Mapfolio, please do **not** open a public issue.

Instead, please report security vulnerabilities privately via:
- **GitHub Security Advisory**: [Report a vulnerability](https://github.com/Anurag-amrev-7557/mapfolio/security/advisories/new)
- Or by emailing the project maintainers.

Please provide:
1. Description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal proof of concept.
3. Any proposed mitigations or fixes.

We will acknowledge your report within 48 hours and work with you on a coordinated disclosure.
